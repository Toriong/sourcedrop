## Creating the Assets

### Prerequisites
- Chrome browser with SourceDrop extension installed
- Access to a NotebookLM account (signed in at notebooklm.google.com)
- Screen recording software (built-in Chrome, OBS, etc.)
- Image editing software for screenshots (optional)

### Recording Tips
1. Use 1280x800 resolution for consistency
2. Keep videos short (30-60 seconds)
3. Show cursor movements clearly
4. Avoid personal information in screenshots
5. Use clean, professional example content
6. Ensure good contrast and readability

### If Real NotebookLM Access Not Available
If you cannot access a real NotebookLM account:
1. Create mock pages that closely resemble NotebookLM's UI
2. Add a note in the store listing: "Screenshots show representative UI"
3. Test thoroughly once real access is available
4. Update assets with real screenshots post-launch
